## 📖 Overview

**LapStore** is a full-featured web application designed for buying and selling laptops and accessories. It bridges the gap between vendors and customers through a seamless interface. The system ensures secure transactions via the **PayHere** gateway and provides a comprehensive dashboard for inventory management.

## 🚀 Key Features

### 👤 For Customers
* **🔐 Secure Authentication:** Sign Up, Sign In (Session Management), and Sign Out.
* **🔎 Advanced Search:** Filter products by category, price range, and brand.
* **🛒 Smart Cart:** Dynamic quantity updates and real-time total calculation.
* **💳 Secure Payments:** Integrated **PayHere** gateway for safe transactions.
* **❤️ Wishlist:** Save items to view or purchase later.
* **👤 User Profile:** Manage address books and view past Order History.
* **✅ Account Verification:** Email verification system using JavaMail.

### 🛠 For Vendors / Admins
* **📊 Dashboard:** Real-time overview of sales performance and revenue.
* **📦 Product Management:** CRUD operations for inventory (Upload images, edit details).
* **⚙️ Store Settings:** Manage vendor profile and configurations.
